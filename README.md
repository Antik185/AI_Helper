# Discord Translate Helper

Расширение для Chrome/Edge/Firefox, которое:
1. Добавляет под каждым сообщением в Discord кнопку **«🌐 Перевести»** — перевод появляется под оригиналом.
2. Добавляет рядом с полем ввода кнопку, которая переводит твой набранный текст на нужный язык (по умолчанию EN) и подставляет его обратно в поле — остаётся только нажать Enter.

## Структура

```
discordHelper/
├── manifest.json        — манифест MV3
├── background.js        — service worker; вызовы API перевода
├── content.js           — контент-скрипт для discord.com
├── content.css          — стили UI
└── popup/
    ├── popup.html
    ├── popup.css
    └── popup.js         — настройки (провайдер, языки, ключи)
```

## Установка

### Chrome / Edge
1. Открой `chrome://extensions/`
2. Включи **Режим разработчика** (верх справа).
3. Нажми **«Загрузить распакованное»** → выбери папку `E:\discordHelper`.
4. Открой Discord в веб-версии (`https://discord.com/app`) — обнови, если был открыт.
5. Кликни иконку расширения → выбери провайдера и язык → **«Сохранить»**.

### Firefox
1. Открой `about:debugging#/runtime/this-firefox`.
2. **«Загрузить временное дополнение…»** → укажи `manifest.json`.
3. Дальше — как в Chrome.

## Провайдеры перевода

- **Google Translate (gtx)** — бесплатно, без ключа. Неофициальный публичный endpoint, может быть лимит по IP.
- **MyMemory** — бесплатно. Указав email, поднимаешь дневной лимит до ~50k слов.
- **DeepL** — нужен API-ключ (free tier: 500k симв/мес). Ключ с суффиксом `:fx` — бесплатный.
- **LibreTranslate** — открытый, можно поднять свой инстанс или использовать публичный.

## Что дальше (идеи)

- Автоперевод всех новых входящих сообщений без клика (опционально, чтобы не сжечь лимит API).
- Хоткей на перевод-и-вставку в инпуте (например, `Ctrl+Shift+T`).
- Кеш переводов, чтобы не дёргать API повторно для одинаковых сообщений.
- Поддержка серверных голосовых каналов / сторис не нужна — фокус на текстовых чатах.
- Иконки расширения (`icons/16.png`, `48.png`, `128.png`) — сейчас используется дефолтная.

## Известные нюансы

- Discord часто переименовывает свои хешированные CSS-классы. Мы цепляемся к стабильным якорям:
  `li[id^="chat-messages-"]`, `div[id^="message-content-"]`, `div[role="textbox"][data-slate-editor="true"]`.
  Если Discord что-то поменяет — править надо здесь.
- Вставка переведённого текста в инпут идёт через `document.execCommand('insertText', ...)` — Slate.js
  слушает соответствующий `beforeinput` и корректно обновляет своё дерево.
