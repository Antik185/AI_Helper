# Discord-десктоп: версии плагина

Два варианта, выбирай один:

## 🟣 Vencord (рекомендую) — [vencord/](./vencord/)

Современный клиент-мод. Плагин нативно интегрирован в React-дерево Discord:
- Кнопка перевода через `addAccessory` (под сообщением)
- Кнопка инпута через `addChatBarButton` (рядом с эмодзи)
- Настройки в родной панели Vencord

**Минус:** установка через сборку из исходников (нужен git/node/pnpm).

## 🟢 BetterDiscord — [betterdiscord/](./betterdiscord/)

Старый-добрый клиент-мод. Плагин — один `.plugin.js` файл.
- Один установщик BetterDiscord (5 минут)
- Просто скопировать файл в папку plugins
- Без сборки, без TypeScript

**Минус:** менее производительный (использует MutationObserver), кнопка инпута — плавающая, а не в чат-баре.

## Функционал — одинаковый

Оба плагина дают:
- Перевод любого сообщения по клику
- Перевод своего текста перед отправкой
- 6 провайдеров: Google, Gemini, OpenRouter, MyMemory, DeepL, LibreTranslate
- Дефолтный OpenRouter-ключ встроен (можно сразу пользоваться)

## Про баны

Оба мода формально нарушают Discord ToS, но:
- Vencord и BetterDiscord давно существуют, баны за их использование — редкие
- Наш плагин в безопасной категории: только UI-изменения, никакой автоматизации
- Все переводы — только по явному клику пользователя
- Никаких запросов к Discord API, только к внешним сервисам перевода

**Чего точно не делать:** ставить плагины-«автоматизаторы» (авто-ответчики, накрутка реакций) — за такое банят.
