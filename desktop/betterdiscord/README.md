# Discord Translate Helper — десктопная версия (BetterDiscord)

Плагин для Discord-десктопа, работает через [BetterDiscord](https://betterdiscord.app/).

Функционал тот же, что у браузерного расширения:
- 🌐 Кнопка перевода под каждым сообщением
- 🌐→XX Кнопка перевода своего текста рядом с полем ввода (плавно появляется при наборе)
- 6 провайдеров перевода: Google, Gemini, OpenRouter, DeepL, MyMemory, LibreTranslate

## Установка

### Шаг 1 — поставить BetterDiscord

Один раз на машину.

1. Открой https://betterdiscord.app/, скачай установщик для своей ОС.
2. **Закрой Discord полностью** (через трей правым кликом → «Quit Discord», не просто крестик).
3. Запусти установщик BetterDiscord. Выбери «Install BetterDiscord» → выбери свою установку Discord (обычно «Discord Stable») → Install.
4. Запусти Discord. В настройках слева снизу должны появиться новые пункты: **Themes**, **Plugins**, **Custom CSS**.

### Шаг 2 — положить наш плагин

1. В Discord открой **User Settings → Plugins → Open Plugins Folder** (откроется папка `%appdata%\BetterDiscord\plugins` на Windows).
2. Скопируй туда файл [`DiscordTranslateHelper.plugin.js`](DiscordTranslateHelper.plugin.js) из этой папки.
3. Вернись в Discord, на странице Plugins должен появиться **DiscordTranslateHelper** — включи тумблер.

### Шаг 3 — настроить

На той же странице Plugins у `DiscordTranslateHelper` есть иконка ⚙ (Settings). Открой и выбери:
- **Translation provider** — `OpenRouter` требует собственный API-ключ. Альтернатива — `Google Translate` (бесплатно, без ключей).
- **Translate incoming messages to** — на какой язык переводить входящие.
- **My messages: from / to** — что и на что переводить, когда жмёшь кнопку у инпута.

Зайди в любой чат — рядом с каждым сообщением появится «🌐 Translate». Начни печатать — справа над инпутом всплывёт «🌐→EN» (или твой целевой код).

## Про баны

Сами по себе клиент-моды (BetterDiscord, Vencord) формально нарушают Discord ToS. На практике баны бывают **только за обвес плагинов, который автоматизирует поведение пользователя** (бот-фичи, спам, многоконтинг, накрутка, токен-грабберы).

Этот плагин не делает ничего из этого:
- Все переводы — только по явному клику. Никакого автоперевода всех сообщений
- Никаких автоматических отправок сообщений. Перевод твоего текста только подставляется в инпут, отправляешь сам Enter'ом
- Никаких запросов к Discord API — только к внешним сервисам перевода
- Никакого логирования или передачи токенов

Категория «безопасных» модов. За BD/Vencord с такими плагинами банят исчезающе редко.

**Чего точно не стоит делать:** ставить вместе с этим плагином всякие «авто-ответчики», «накрутку реакций» и прочую автоматизацию — вот за такое баны бывают.

## Обновление

Когда выйдет новая версия — просто перепиши файл `DiscordTranslateHelper.plugin.js` в папке plugins. BD автоматически перезагрузит плагин.

## Удаление

В Discord → Plugins → выключи тумблер у плагина, удали файл из папки plugins. Полностью удалить BetterDiscord можно тем же установщиком (Remove BetterDiscord).
